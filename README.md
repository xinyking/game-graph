# 游戏厂商图谱 · Game Atlas

仓库包含完整网页、数据编辑源、地图原始数据和验证脚本。运行 `npm start` 本地预览，`npm test` 验证。Cloudflare Pages 自动部署配置见 [DEPLOY.md](DEPLOY.md)。`assets/source/world-land.geojson` 用于离线重建地图；截图、临时下载和其他任务文件不进入仓库。

基于 [Essie363/MusicalGraph](https://github.com/Essie363/MusicalGraph) 的游戏产业适配版。

直接打开 `dist/index.html` 即可离线使用；若要 HTTP 预览，在本目录运行 `node server.cjs`，访问 http://127.0.0.1:4173。

## 功能

- 首页提供“Game Graph”和“世界地图”两个入口；默认关系图谱使用 Game Graph星图，图内可随时切换，保留当前搜索与选中节点。

- 中英文与别名搜索：输入名称，点击结果或按 Enter 聚焦。
- 厂商、工作室、作品、股东四类节点；地区筛选；组织归属、开发、发行、控制、参股五类连线。
- 每个节点都有属性面板；游戏包含玩法简介、类型、开发方、发行方与作品口径。股东节点使用紫色菱形，点击可查看共同控制或投资的厂商。
- 点击图中节点或左侧目录查看详情和每条关系的来源。点击空白或按 Esc 返回全景。
- 拖动平移、滚轮缩放；触屏支持双指缩放；画布方向键平移、加减键缩放。
- 最短关系路径：以当前筛选的关系为准，允许双向遍历；语义按原始方向展示。
- 导出当前视图的可编辑 SVG，或当前可见节点、边与来源的 JSON。

## 数据口径

当前数据包含 37 家厂商、17 个工作室、115 款游戏与系列、6 个股东或控制主体，共 175 个节点、190 条关系（其中 17 条资本关系）。

`build_data.py`、`catalog_extension.py` 与 `enrichment.py` 为可维护的编辑数据源，`city-reference.json` 保存城市坐标。执行后生成 `dist/data.json`、`dist/data.js`、逐家地点表 `location-correspondence.csv` 和股权关系表 `shareholding-correspondence.csv`。网页无需服务也能运行。

资本关系采用有方向的“股东 → 被投资机构”，共同股东形成两步连接，不创建厂商之间虚构的直接股权边。控制关系与少数参股分别记录；比例仅对应关系中的报告日期，间接持股注明经由主体。腾讯控股与腾讯游戏业务分为两个节点；索尼集团与 SIE 也分开。尚未收录股东不能解读为没有股东，组织归属也不自动等同于法律股权。KIRKBI 与 Disney 的记录保留公告阶段及交割核实状态；不以投资金额反推比例。股权信息并非全部厂商的完整或实时股东名册。

自然人不定位私人住址；未核对地点的资本主体只在星图中展示。地图切换会排除这些未定位节点。游戏产品简介为简要编辑描述，来源链接指向相应官方产品或发行资料；不同版本、区域与平台的完整发行链可能未全部收录。

核对日期为 2026-10-11。这是精选样本，并非完整产业或实时股权数据库。各关系可追溯到对应公开来源；旧公告和年报在详情注明时间。组织归属可能省略中间法律主体；工作室的发行合作不自动转化为股权关系。地区是组织或开发方的粗粒度分类，不是游戏发行范围。

HoYoverse（新加坡）与米哈游（上海）分别展示；微软 / Xbox 作为品牌或业务视图合并展示。部分“作品”是系列而非单款游戏，名称及描述有标注。没有路径不代表现实中没有合作，只表示数据集没有记录。

## 与 MusicalGraph 的关系

阅读的上游版本：`84e5440b837156e1ba6511307d62f32e33309447`。

沿用其零依赖 Canvas 星图、搜索聚焦、侧栏详情和静态数据架构。`dist/graph-engine.js` 的斥力、弹簧、阻尼步骤适配自上游 `web/app.js` 的 `physicsStep`。新版按实际关系形成连通分量，所有关系（包括跨公司开发与发行）参与布局，公司点位不再固定为独立岛屿。没有已记录关系的分量紧凑排列，不增加虚构连线。全景显示团队和作品名称，选中后展示关系文字和方向。其他页面与交互为游戏领域重新编写。

没有连接原项目 Supabase、认证、反馈服务或音乐剧数据。上游未发现许可证文件；本交付为本地适配版本，没有向公共站点或原仓库推送。

## 维护与验证

重新生成数据：`python build_data.py`。

数据、布局及路径验证：`node verify.cjs`。

扩展数据时为每条边填写来源。不能从发行、联合开发或投资关系推断“旗下工作室”；需要准确股权图时，应另外添加法律实体、比例、有效期与公告日期。

## 世界地图与动效

世界地图模式逐家对应已核对的城市参考坐标，不再按地区设置锚点或移动机构坐标。同城机构共享一个标记，点击展开后可分别查看详情；“地点对照”逐项列出城市、定位口径、经纬度和公开来源。城市参考点不等同于办公楼地址：总部、主要工作室、官方联系城市按证据分别注明。游戏坐标继承记录中的开发团队（缺失时采用发行方），详情显示对应机构。多地办公机构只展示注明口径的代表城市。

右上角可切换关系星图。地图陆地轮廓来自 [Natural Earth 1:110m 公有领域数据](https://www.naturalearthdata.com/downloads/110m-physical-vectors/110m-land/)，已包含在 `dist/world-map.js`。城市坐标主要来自 [GeoNames](https://www.geonames.org/)，遵循其 [CC BY 许可](https://www.geonames.org/export/)。果川采用公开城市参考点，精度与来源单独注明。

首页支持文字入场、星光与连线描绘；图谱支持光点呼吸与关系粒子流动。系统开启减少动态效果时关闭装饰动画；后台与首页暂停 Canvas 重绘。
